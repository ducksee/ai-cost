# AI Cost Metadata

Public JSON catalogs for AI provider and model pricing metadata.

## Files

- `model_metadata_catalog.json` — model aliases, provider mapping, and token pricing.
- `provider_metadata_catalog.json` — provider aliases and display metadata.
- `metadata_manifest.json` — published file hashes and counts.

## Stable Raw URLs

```text
https://raw.githubusercontent.com/ducksee/ai-cost/main/model_metadata_catalog.json
https://raw.githubusercontent.com/ducksee/ai-cost/main/provider_metadata_catalog.json
```

The generation scripts are intentionally kept outside this public repository.
